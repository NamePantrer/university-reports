# ПР4. Оценка экономической эффективности программного проекта

(5 страниц) и `.docx`. Титульный лист убран из обоих файлов.

Расчёт по пособию Павловой Е.А. (п. 4.2 и 4.4) для ИС «АудитИБ» из ПР3.
Статические методы: Qk = 4 клиента, RI = 50 %, ARR = 92,3 %, PP = 2,31 года.
Динамические: NPV = 185 354 руб., A = 64 923 руб./год, PI = 1,386,
IRR = 31,36 %, DPP = 2,92 года. Все критерии выполнены.
