# ПР3. Технико-экономическое обоснование проекта ИС (ГОСТ 24.202-80)

**Отчёт:** [`ОЭЗИ_ПР3_ТЭО_проекта_ИС_АудитИБ.pdf`](ОЭЗИ_ПР3_ТЭО_проекта_ИС_АудитИБ.pdf)
(8 страниц) и `.docx`, плюс презентация `ОЭЗИ_ПР3_ТЭО_презентация.pptx`.
Титульный лист убран из PDF и DOCX, титульный слайд — из презентации
(осталось 7 слайдов).

ТЭО информационной системы «АудитИБ» для ООО «СеверМодуль» в полном составе
разделов ГОСТ 24.202-80. Система ведёт учёт аудитов ИБ на производстве:
реестр объектов, чек-листы, журнал несоответствий, отчёты. Инвестиции
480 000 руб., срок MVP 5 месяцев. NPV = 185 354 руб., PI = 1,39,
IRR ≈ 31,4 %, PP ≈ 2,3 года. Решение о создании положительное.
