# ПР1. Ценообразование информационного продукта

**Отчёт:** [`ОЭЗИ_ПР1_Ценообразование_информационного_продукта.pdf`](ОЭЗИ_ПР1_Ценообразование_информационного_продукта.pdf)
(5 страниц) и редактируемый `.docx`. Титульный лист убран из обоих файлов.

Инфопродукт — видеокурс «Аудит ИБ на малом производстве» для ООО «СеверМодуль»
(8 модулей, затраты 95 000 руб., 50 копий). Цена посчитана четырьмя способами
из методички: затратный метод — 3 800 руб., по времени автора — 2 200 руб.,
по продажам аналога — 5 556 руб., доля от полезности — 6 000 руб.

## Из архива `oezi_pr1.rar`

| Файл | Что это |
|---|---|
| `ОЭЗИ_ПР1_…docx / .pdf` | отчёт (в архиве: `Калинкин_ПВ_ПР1_ОЭЗИ.*`) |
| `ОЭЗИ_ПР1_расчет.xlsx` | исходная расчётная таблица (значения) |
| `задание_ПР1_ОЭЗИ.docx` | задание и методичка с примерами четырёх способов |

## Сопутствующие файлы (сгенерированы по описанию в отчёте)

| Файл | Что это |
|---|---|
| `код/pricing.py`, `код/input.json` | расчёт четырёх способов. С ключом `--xlsx` строит книгу с формулами |
| `ОЭЗИ_ПР1_расчет_формулы.xlsx` | та же таблица, но с живыми формулами Excel вместо чисел |
| `материалы/программа_курса.md` | программа 8 модулей курса, который описан в отчёте |
| `материалы/чек-лист_обхода_цеха.md` | чек-лист обхода цеха из комплекта курса |
| `материалы/шаблон_регламента_резервного_копирования.md` | шаблон регламента из комплекта курса (резервное копирование конфигураций ПЛК/HMI) |

```bash
python3 код/pricing.py      # 3800 / 2200 / 5556 / 6000 руб.
```
