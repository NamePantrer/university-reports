# ЛР5. Тестирование файловых систем

**Отчёт:** [`ОС_ЛР5_Тестирование_файловых_систем.docx`](ОС_ЛР5_Тестирование_файловых_систем.docx) (титульный лист убран).

Сравнение ext4, XFS, btrfs и F2FS (усложнённый вариант) на loop-образах по
768 МиБ: последовательный ввод-вывод блоками 1 МиБ, случайный 4 КБ (fio),
создание и удаление 4000 мелких файлов. Перед этим отработаны образ NTFS,
loop, таблица разделов с kpartx и LVM (pvmove, lvresize). По интегральной
оценке S лучшей оказалась F2FS (0,966), по последовательной записи — XFS.

## Сопутствующие файлы (сгенерированы по описанию в отчёте)

| Файл | Что это |
|---|---|
| `код/disk_image_ops.sh` | раздел 1.2: образ NTFS через ntfs-3g, losetup, два раздела и kpartx (ext4 + XFS), LVM из двух PV с vgcreate -s 32M, pvmove, lvresize до 96 МиБ |
| `код/fs_bench.sh` | методика 1.4–1.7 и приложение А: для каждой ФС новый образ, mkfs (время), прогрев 64 МиБ, 2 прогона fio (seq 1M / rand 4k, 8 с) и тест метаданных, сброс кэша между прогонами; итог в CSV |
| `код/score.py` | нормирование к лучшему и интегральный показатель S (таблица 5), `--plot` строит рисунки 1 и 2 |
| `данные/fs_summary_2026-10-02.csv` | средние значения из таблиц 2–4 |
| `данные/fs_seq_runs_2026-10-02.csv` | два прогона последовательной записи и чтения (таблица 2) |

```bash
python3 код/score.py                      # F2FS 0.966, ext4 0.906, XFS 0.717, btrfs 0.363
sudo FS_LIST="ext4 xfs f2fs" ./код/fs_bench.sh && python3 код/score.py fs_bench_*.csv
```

Зависимости `fs_bench.sh`: fio ≥ 3, jq, e2fsprogs, xfsprogs, btrfs-progs, f2fs-tools.
