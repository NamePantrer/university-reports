# ЛР4. Планировщик ввода-вывода

**Отчёт:** [`ОС_ЛР4_Планировщик_ввода-вывода.docx`](ОС_ЛР4_Планировщик_ввода-вывода.docx) (титульный лист убран).

Сравнение планировщиков ввода-вывода Linux `none`, `kyber`, `bfq` и `mq-deadline`
на виртуальном диске WSL2 (NVMe KINGSTON SNV3S2000G) с помощью `hdparm -tT`
и прямого чтения 4 КБ. Контрольная серия с разным порядком запуска исключает
влияние прогрева кэша. По `hdparm -t` лучший средний результат у BFQ
(3514,96 МБ/с), минимальная задержка одиночного чтения у `none`. Усиленный
вариант: у Kyber целевая задержка чтения уменьшена с 2 мс до 1 мс.

## Сопутствующие файлы (сгенерированы по описанию в отчёте)

| Файл | Что это |
|---|---|
| `код/run_schedulers.sh` | скрипт из приложения А: kyber → bfq → none, `hdparm -tT`, пауза 15 с |
| `код/control_series.sh` | контрольная серия (раздел 1.5): 2 прогрева и 3 круга с ротацией порядка, результат в CSV; `SERIES=mq` — 4 круга с mq-deadline (раздел 1.6) |
| `код/odirect_latency.c` | задержка одиночного чтения 4 КБ с `O_DIRECT`: 30 прогревочных и 300 измерений, фиксированный набор смещений, p50/p99 |
| `код/parallel_direct_read.c` | 8 процессов × 400 блоков по 128 КБ прямым доступом (раздел 2.3) |
| `код/kyber_latency_target.sh` | смена `read_lat_nsec` 2 → 1 → 2 мс на работающем Kyber, проверка обратным чтением, `hdparm` на каждой цели |
| `код/kyber-read-lat-1ms.patch` | правка `block/kyber-iosched.c` (приложение Б): `KYBER_READ` 2 мс → 1 мс; сделана против текущего исходника ядра, применяется `patch -p1` |
| `код/analyze.py` | пересчёт средних и отставаний от лидера (таблицы 2, 4, 5) из CSV |
| `данные/*.csv` | числа из таблиц 1–6 отчёта |

```bash
cd код && make                       # odirect_latency, parallel_direct_read
sudo ./run_schedulers.sh sdd
sudo ./odirect_latency /dev/sdd 300 30
python3 analyze.py                   # BFQ 3514.96, отставание none 1.84 %, kyber 2.81 %
```

> Скрипты переключают планировщик реального блочного устройства и сбрасывают
> страничный кэш, поэтому запускаются от root и только на тестовом стенде.
