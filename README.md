Лабораторные и практические работы по трём дисциплинам, факультет безопасности
информационных технологий (ФБИТ), Университет ИТМО, группа N3249, 2026 г.
Автор — Пётр Калинкин. Лабораторные по ОС выполнены вдвоём с Сергеем Евдокимовым.

К каждой работе приложены отчёт и сопутствующие файлы: код, скрипты, данные,
шаблоны документов. Внутри каждой папки есть свой `README.md` с описанием и
командами запуска.

## Операционные системы (ОС)

Эксперименты с подсистемами ядра Linux на стендах WSL2 и VirtualBox: замеры
и сравнение реализаций.

| Работа | Тема | Сопутствующие файлы |
|---|---|---|
| [ЛР4](ОС/ЛР4_Планировщик_ввода-вывода/) | Планировщик ввода-вывода: none / kyber / bfq / mq-deadline, правка целевой задержки Kyber | скрипты переключения и замеров, C-программы прямого чтения, патч `kyber-iosched.c`, CSV, анализ |
| [ЛР5](ОС/ЛР5_Тестирование_файловых_систем/) | Тестирование файловых систем: ext4, XFS, btrfs, F2FS; loop, kpartx, LVM | скрипты операций с образами и бенчмарка fio, расчёт интегральной оценки |
| [ЛР6](ОС/ЛР6_malloc_free_и_аллокаторы/) | malloc/free и сравнение аллокаторов glibc, jemalloc, mimalloc, tcmalloc | бенчмарк на C, скрипт запуска, построение графиков и таблиц |

Нормативная база и методы ИБ: базы уязвимостей и CVSS, РД ФСТЭК, экспертные
оценки, деловая игра по инциденту.

| Работа | Тема | Сопутствующие файлы |
|---|---|---|
| [ЛР1](ТИБиМЗИ/ЛР1_Базы_угроз_и_калькулятор_CVSS/) | Базы данных угроз и уязвимостей, калькулятор CVSS | калькулятор CVSS 3.0/3.1 с тестами, сравнение баз |
| [ЛР2](ТИБиМЗИ/ЛР2_РД_ФСТЭК_классы_АС_СВТ_МЭ/) | РД ФСТЭК: классы АС, СВТ и МЭ на семи кейсах | классификатор по РД с кейсами и тестами, памятка |
| [ЛР3](ТИБиМЗИ/ЛР3_Экспертные_оценки/) | Экспертные оценки: непосредственная оценка, ранжирование, МАИ | реализация трёх методов, данные, анкеты экспертов |
| [ЛР4](ТИБиМЗИ/ЛР4_Деловая_игра_NotPetya/) | Деловая игра-квест по инциденту NotPetya | сценарий JSON, консольная игра, карточки ролей и бланк ведущего |

## Оценка эффективности защиты информации (ОЭЗИ)

Экономика ИБ на сквозном кейсе ООО «СеверМодуль» (малое производство):
ценообразование инфопродукта, ущерб от угрозы, ТЭО информационной системы,
инвестиционные показатели.

| Работа | Тема | Сопутствующие файлы |
|---|---|---|
| [ПР1](ОЭЗИ/ПР1_Ценообразование_инфопродукта/) | Ценообразование информационного продукта (4 способа) | калькулятор цены, книга с формулами, программа курса, чек-лист обхода цеха, шаблон регламента |
| [ПР2](ОЭЗИ/ПР2_Ущерб_от_угрозы_ИБ/) | Ущерб от угрозы ИБ производственному процессу, упущенная выгода | расчёт ущерба, книга с формулами, служебная записка об обосновании СЗИ |
| [ПР3](ОЭЗИ/ПР3_ТЭО_ИС_АудитИБ/) | ТЭО ИС «АудитИБ» по ГОСТ 24.202-80 | схема БД и прототип ИС, регламент аудита, план-график работ |
| [ПР4](ОЭЗИ/ПР4_Эффективность_проекта/) | Эффективность проекта: Qk, RI, ARR, PP, NPV, PI, IRR, DPP | калькулятор показателей, книга с формулами |

Работы ОЭЗИ сдавались RAR-архивами. Здесь лежит их распакованное содержимое:
отчёт (DOCX и PDF), исходная расчётная книга Excel, задание преподавателя, для
ПР3 — ещё презентация.

## Примечания

- Титульные листы убраны из всех отчётов: в PDF вырезаны титульные страницы
  (в ПР2 ОЭЗИ — ещё и пустая страница за титулом), в DOCX удалён титульный блок
  вместе с изображениями подписей, в презентации ПР3 — титульный слайд.
  Нумерация страниц в DOCX начинается с 2, как в исходниках, поэтому номера
  страниц в содержании остаются верными.
- Часть сопутствующих файлов сгенерирована как иллюстрация к отчётам. Это
  скрипты, программы, расчётные книги с формулами, шаблоны документов, анкеты,
  сценарии. Они восстановлены по тому, что описано в тексте отчётов, и
  проверены на совпадение с приведёнными в них числами. Исходные данные
  экспериментов взяты из таблиц отчётов. Код из приложений ЛР6 по ОС перенесён
  без изменений (добавлены только комментарии). Скрипт из приложения А ЛР4 и
  команды из приложения А ЛР5 оформлены в запускаемые скрипты с проверками.
  Остальное в папках `код/`, `данные/` и `материалы/` создано при подготовке
  репозитория.
- Программы на Python требуют Python 3.8+. Почти везде хватает стандартной
  библиотеки, исключения: `openpyxl` (книги Excel), `matplotlib`/`pandas`
  (графики).
