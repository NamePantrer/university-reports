# ЛР2. Руководящие документы ФСТЭК. Классификация АС, СВТ и МЭ

**Отчёт:** [`ТИБиМЗИ_ЛР2_РД_ФСТЭК_классификация_АС_СВТ_МЭ.pdf`](ТИБиМЗИ_ЛР2_РД_ФСТЭК_классификация_АС_СВТ_МЭ.pdf) (18 страниц; титульная страница вырезана).

Разбор РД Гостехкомиссии (термины, концепция защиты от НСД, классификация АС,
показатели защищённости СВТ и МЭ), 187-ФЗ о КИИ и Методики оценки угроз ФСТЭК
2021 г. Для семи кейсов обоснованы классы АС, СВТ и МЭ, выведен порядок решения
таких задач.

## Сопутствующие файлы (сгенерированы по описанию в отчёте)

| Файл | Что это |
|---|---|
| `код/fstec_classifier.py` | подбор класса АС и минимальных классов СВТ/МЭ по порядку из раздела 2 (гриф → пользователи → АС → СВТ → МЭ → КИИ/ПДн → оценка угроз) |
| `код/cases.json` | семь кейсов отчёта (кейс 5 — в двух вариантах: «как описали» и «как нужно») |
| `код/test_fstec_classifier.py` | сверка со сводной таблицей 11 и с п. 2.18 РД |
| `материалы/порядок_выбора_классов.md` | памятка: алгоритм и таблицы соответствия классов |

```bash
cd код
python3 fstec_classifier.py                       # сводная таблица по всем кейсам
python3 fstec_classifier.py --info СС --users equal   # 2А, СВТ 3, МЭ 2
python3 -m unittest test_fstec_classifier
```
