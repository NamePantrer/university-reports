# ЛР4. Деловая игра по информационной безопасности

**Отчёт:** [`ТИБиМЗИ_ЛР4_Деловая_игра_по_ИБ.pdf`](ТИБиМЗИ_ЛР4_Деловая_игра_по_ИБ.pdf) (8 страниц; титульная страница вырезана).

Сценарий игры-квеста по реальному инциденту: эпидемия шифровальщика NotPetya
(2017 г.), заражение через обновление доверенного ПО. В игре пять этапов и пять
ролей (SOC, системный администратор, IR, CISO, PR/юрист), решения дают 3, 2 или
0 баллов. Итоговый ущерб зависит от суммы баллов (максимум 15).

## Сопутствующие файлы (сгенерированы по описанию в отчёте)

| Файл | Что это |
|---|---|
| `код/scenario.json` | сценарий: этапы, ситуации, привязка к Методике ФСТЭК (последствия / объекты / способы), варианты решений, роли, исходы |
| `код/quest.py` | консольная версия игры: интерактивно или `--auto max\|mid\|min\|random`, учёт недостающих ролей |
| `код/test_quest.py` | проверка правил подсчёта и таблицы исходов |
| `материалы/карточки_ролей_и_бланк_ведущего.md` | раздаточные карточки ролей, бланк подсчёта баллов, эталон решений |

```bash
cd код
python3 quest.py                         # играть
python3 quest.py --roles SOC,ADMIN --auto max
python3 -m unittest test_quest
```

Правило «решение засчитывается, только если в команде есть нужная роль, иначе
ход тратится на обучение» реализовано так: на этап даётся два хода. Если оба
хода ушли на привлечение ролей, этап даёт 0 баллов.
