# ЛР1. Исследование баз данных угроз и уязвимостей. Калькулятор уязвимостей

**Отчёт:** [`ТИБиМЗИ_ЛР1_Базы_угроз_и_калькулятор_CVSS.pdf`](ТИБиМЗИ_ЛР1_Базы_угроз_и_калькулятор_CVSS.pdf) (10 страниц; титульная страница вырезана).

Обзор пяти баз (БДУ ФСТЭК, NVD, Vulners, JVN, Exploit-DB), оценка уязвимостей
калькулятором CVSS 3.0 по базовым (8.5), временным (8.0) и контекстным (7.8)
метрикам, отличия CVSS 3.1 от CVSS 4.0.

## Сопутствующие файлы (сгенерированы по описанию в отчёте)

| Файл | Что это |
|---|---|
| `код/cvss3.py` | калькулятор CVSS v3.0/v3.1 (базовая, временная, контекстная оценки) по спецификации FIRST; `--lab` пересчитывает три задачи отчёта |
| `код/test_cvss3.py` | проверка на эталонных векторах и на задачах ЛР |
| `материалы/сравнение_баз_угроз_и_уязвимостей.md` | сводная таблица пяти баз, таблица отличий CVSS 3.1 и 4.0, векторы задач |

```bash
cd код
python3 cvss3.py --lab          # 8.5 / 8.0 / 7.8 — как в отчёте (калькулятор 3.0)
python3 cvss3.py "CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H"   # 9.8 Critical
python3 -m unittest test_cvss3
```

Векторы восстановлены по словесным условиям задач: временная оценка 8.0
получается при `E:F/RL:W/RC:C`. Для контекстной задачи калькулятор 3.0 даёт 7.8,
а версия 3.1 — 7.9: в 3.1 изменена формула ModifiedImpact при изменённой
области. Скрипт показывает обе версии.
