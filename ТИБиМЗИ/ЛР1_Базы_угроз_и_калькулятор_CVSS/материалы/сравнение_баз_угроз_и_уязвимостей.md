## Отличия CVSS 3.1 и CVSS 4.0 (к разделу 3.4)

| Что | CVSS 3.1 | CVSS 4.0 |
|---|---|---|
| Обозначение итоговой оценки | Base / Temporal / Environmental | CVSS-B, CVSS-BT, CVSS-BE, CVSS-BTE (видно, какие группы метрик учтены) |
| Сложность атаки | AC (Low/High) | AC + новая метрика AT (Attack Requirements) |
| Взаимодействие с пользователем | UI: None / Required | UI: None / Passive / Active |
| Область | Scope (U/C) | Scope убран; влияние на уязвимую систему (VC/VI/VA) и на последующие системы (SC/SI/SA) |
| Временные метрики | E, RL, RC | группа «Threat»: осталась только E (Attacked / PoC / Unreported); RL и RC убраны, High и Functional объединены в Attacked |
| Дополнительные метрики | нет | Supplemental: Safety, Automatable, Recovery, Value Density, Response Effort, Provider Urgency |

## Векторы задач ЛР1

Пересчитываются скриптом `../код/cvss3.py --lab`.

| Задача | Вектор | Оценка (калькулятор 3.0) |
|---|---|---|
| г) базовые | `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:C/C:H/I:N/A:L` | BS = 8.5 (High) |
| д) временные | `… /E:F/RL:W/RC:C` | TS = 8.0 (High) |
| в) контекстные | `… /CR:H/IR:H/AR:H/MAV:L/MAC:L/MPR:H/MUI:N/MS:X/MC:H/MI:H/MA:H` | ES = 7.8 (High) |

Расшифровка контекстной задачи: высокие требования к К, Ц и Д (CR/IR/AR:H),
влияние на них высокое (MC/MI/MA:H), атака низкой сложности (MAC:L) на
локальном уровне (MAV:L), высокие привилегии (MPR:H), без участия
пользователя (MUI:N), влияние на другие компоненты неизвестно (MS:X —
остаётся базовое S:C).
