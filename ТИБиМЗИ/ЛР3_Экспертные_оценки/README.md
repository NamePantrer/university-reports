# ЛР3. Экспертные оценки

**Отчёт:** [`ТИБиМЗИ_ЛР3_Экспертные_оценки.pdf`](ТИБиМЗИ_ЛР3_Экспертные_оценки.pdf) (9 страниц; титульная страница вырезана).

Три задачи оценки ситуаций ИБ интернет-магазина. Метод непосредственной
оценки: коэффициент вариации, I = 6,47. Ранжирование мер защиты: коэффициент
конкордации Кендалла W = 0,824, χ² = 16,48. Метод анализа иерархий Саати:
веса направлений бюджета, ОС = 0,015.
