# Анкеты для экспертов (к ЛР3)

Бланки, которые раздаются экспертам в трёх задачах отчёта. Заполненные
результаты лежат в `../данные/*.csv`, обработка — `../код/expert_methods.py`.

---

## Анкета 1. Непосредственная оценка уровня угроз ИБ интернет-магазина

**Объект оценки:** сайт небольшого интернет-магазина, который обрабатывает
персональные данные и платежи покупателей.

**Инструкция.** Оцените независимо от других экспертов уровень угрозы по каждому
вопросу по шкале от **0** (угроза отсутствует) до **10** (критическая угроза).
Ставьте целое число. Не обсуждайте оценки с другими экспертами до сдачи анкеты.

Эксперт: ____________________  Дата: ____________

| № | Вопрос | Вес (для организатора) | Оценка 0–10 |
|---|---|---|---|
| В1 | Насколько велика угроза эксплуатации уязвимостей веб-приложения (SQL-инъекции, XSS)? | 0,30 | |
| В2 | Насколько велика угроза из-за слабой парольной политики и отсутствия MFA? | 0,15 | |
| В3 | Насколько велика угроза компрометации платёжного контура? | 0,25 | |
| В4 | Насколько велика угроза потери данных из-за недостатков резервного копирования и восстановления? | 0,20 | |
| В5 | Насколько велика угроза успешного фишинга из-за недостаточной обученности персонала? | 0,10 | |

*Обработка:* среднее и выборочное СКО по каждому вопросу, коэффициент вариации
V = σ / x̄ · 100 % (согласовано при V < 33 %), интегральная оценка
I = Σ wᵢ · x̄ᵢ.

## Анкета 2. Ранжирование мер защиты при ограниченном бюджете

**Инструкция.** Расставьте пять мер защиты по приоритету внедрения: **1** — самая
приоритетная, **5** — наименее приоритетная. Каждый ранг используется ровно один
раз (связанные ранги не допускаются).

Эксперт: ____________________  Дата: ____________

| Код | Мера защиты | Справочный вес | Ранг 1–5 |
|---|---|---|---|
| A | Внедрение межсетевого экрана уровня приложений (WAF) | 0,25 | |
| B | Переход на многофакторную аутентификацию (MFA) | 0,20 | |
| C | Сегментация сети | 0,20 | |
| D | Система мониторинга событий (SIEM) | 0,20 | |
| E | Обучение персонала по фишингу | 0,15 | |

*Обработка:* суммы рангов Rⱼ, коэффициент конкордации Кендалла
W = 12·S / (m²·(n³ − n)), проверка значимости χ² = m·(n − 1)·W при df = n − 1.

## Анкета 3. Парные сравнения направлений бюджета ИБ (метод Саати)

**Инструкция.** Для каждой пары направлений укажите, какое важнее и во сколько
раз, по шкале Саати:

| Балл | Значение |
|---|---|
| 1 | равная важность |
| 3 | умеренное превосходство |
| 5 | существенное превосходство |
| 7 | значительное превосходство |
| 9 | абсолютное превосходство |
| 2, 4, 6, 8 | промежуточные значения |

Если важнее правое направление, ставьте обратную величину (1/3, 1/5, …).
Заполняется только верхний треугольник, нижний вычисляется как aⱼᵢ = 1 / aᵢⱼ.

Направления: **К1** — уязвимости веб-приложения; **К2** — парольная политика и
MFA; **К3** — платёжный контур; **К4** — резервное копирование; **К5** —
обучение персонала.

| | К1 | К2 | К3 | К4 | К5 |
|---|---|---|---|---|---|
| **К1** | 1 | | | | |
| **К2** | — | 1 | | | |
| **К3** | — | — | 1 | | |
| **К4** | — | — | — | 1 | |
| **К5** | — | — | — | — | 1 |

*Обработка:* веса — нормированный главный собственный вектор матрицы,
λmax, ИС = (λmax − n)/(n − 1), ОС = ИС / СИ (СИ = 1,12 при n = 5); суждения
приемлемы при ОС < 0,10.
